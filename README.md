# schicht_planer
Entwicklung eines Python-Algorithmus zur automatisierten und fairen Schichtplanung mit SCIP. Dabei werden Mitarbeiterverfügbarkeiten, Qualifikationen, Personalbedarf und individuelle Wünsche berücksichtigt. Gleichzeitig dient das Projekt als praktische Vorbereitung auf die Klausur in linearer und ganzzahliger Optimierung.
